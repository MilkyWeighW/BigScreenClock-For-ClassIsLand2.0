## 1. 项目定位

ClassIsland 2.0 的一个**全屏大屏时钟插件**：在教室大屏上全屏显示时间/日期，同时叠加教室分贝、当前课程与进度、提醒（天气/预警/倒计时/文本/降雨/颜文字）、摄像头占用、地震预警，并把「安静/吵闹」按课程统计成计数。由课程状态自动触发全屏、下课自动退出。

它不是「桌宠式小组件」，而是**为教室长亮大屏做的常驻显示端**：防休眠、躲鼠标、最小化暂停、课前预热、内存看门狗规避，全部围绕「一块大屏连续开一整天」这个场景。源码里大量中文注释记录了线上事故（1.40 GiB 内存看门狗、`Visual was invalidated during the render pass` 被 CI 判故障自动禁用、1.1.1.9 上课点名时刻崩溃），这在本项目中是最有价值的工程线索。

`Views/LetterWindow.axaml` 是作者的告别信，声明自 1.2.0.0 起不再加新功能（署名 sokumei 2026/10/31）；`AboutPopupWindow` 的版本徽章（五位=开发版、四位末位≠0=测试版、末位=0=正式版）说明维护已收尾。

## 4. 启动、生命周期与线程模型

**启动链**（`Plugin.cs`）：`Initialize` → 读配置（若已存在则 `ClockThemeApplier.MigrateLegacySettings` 迁移旧颜色）→ 强制 `AdjustingLayout=false` → `AddSingleton`（Settings / DecibelMeterService / CameraActivityService / FullScreenClockViewModel / AutoTriggerService）→ `AddHostedService`（`ServiceProviderCapture` → `AutoTriggerService` → `BackdropPreloadService` → `TrayMenuService`）→ `AddSettingsPage`。

**硬件生命周期绑定「大屏是否可见」**，服务本身不自启硬件：
- `Show()`：起 1s 刷新、进度动画、防休眠、开麦克风、开摄像头；
- `Hide()`/窗口 `Closed`/最小化超时：全部关闭并退订课程事件；
- 最小化：默认 `PauseWhenMinimized=true`、`MinimizePauseMinutes=5`（钳 1–30），窗口与任务栏入口保留，到期暂停监控但保留入口；`Activated` 时 `EnsureFullScreen` 兜底拉回全屏。

**线程模型**：
- UI 线程：时间 1s（`System.Timers.Timer` + `Dispatcher.UIThread.Post`）、音量动画 33ms（`DispatcherTimer`）、弹幕 16ms、组件同步 3s、天气 60s；
- 音频线程：NAudio 回调 → RMS → `NoiseEventDetector.Process(rawRms, 真实 dt)`；
- 摄像头：MF 回调线程整理快照写 `volatile` 字段；
- 玻璃：UI 线程取快照 → `Task.Run` 串行逐块烘焙 → `Dispatcher.Post` 上载（带 stale 校验）。

## 5. 六条运行时数据流

### 5.1 时钟与课程（两条时间轴）
- **显示**用真实 `DateTime.Now`（`FullScreenClockViewModel.cs:1689`）；**课程/进度/打铃/保护期**用 ClassIsland 虚拟时间 `IExactTimeService.GetCurrentLocalDateTime()`（`NowVirtual`，失败退 `DateTime.Now`，`FullScreenClockViewModel.cs:164-171,1702`）。两者相差 `TimeOffsetSeconds`——这是有意设计，但表现为「读数与进度/打铃不齐」。
- 课表不走 DI，**直接解析磁盘 JSON**：`ConfigFolder/../../..` 下 `Settings.json` 取 `SelectedProfile`（缺省 `7.json`）与 `TimeOffsetSeconds`，再读 `Profiles/<profile>` 的 `TimeLayouts`/`ClassPlans`/`Subjects`；按星期选当天班级计划（跳过 `IsOverlay`），`timeType==0` 为上课槽，**按出现顺序与 `Classes[].SubjectId` 顺序匹配**（`FullScreenClockViewModel.cs:1751-1823`，映射无校验）。
- 打铃行：`实际打铃 = 课表时间 − offset`，仅 `ShowBellTime && offset≠0` 时显示。

### 5.2 噪音统计
`NAudio(WaveInEvent, 44.1kHz/16bit/mono) → 逐样本 RMS → NoiseEventDetector(EMA alpha=0.2 按 dt 折算 + 0.8 迟滞分级) → 段状态机 → NoiseCounter → UI 计数`
- 分级阈值默认 Quiet 0.005 / Good 0.015 / Normal 0.04 / Noisy 0.08（噪声事件级另有 `SustainSeconds=1.0` 起算、`FallWindowSeconds=5.0` 回落、占比 `≥0.5` 才算「吵闹」）。
- **一段最多结算一次**：吵够 1s 起算，安静回落超过 5s 窗口才结算；全程持续吵闹不结算，切课被 `StartNewClass` 清零。
- 课间/上课初期保护期不计数（`SkipFirst3Min && 距课表上课 < SkipFirstMinutes`）。
- 音量条五档：0-20 安静 / 20-40 良好 / 40-60 一般 / 60-80 吵闹 / 80-100 嘈杂（`VeryNoisyFactor=1.3`）。
- 看门狗 5s：无数据就整条链路重启（针对睡眠唤醒后句柄失效）。

### 5.3 提醒 / 天气 / 预警
- 天气/温度/预警**直读 CI `Settings.json`** 的 `LastWeatherInfo`（刻意不用 CI 实时天气，规避定位偏差），`weathercn` 两位码 → Lucide 图标名 + 中文描述；每 60s 刷一次。
- 顶部第一行：天气固定主位，按 降雨 > 倒计时 > 文本 贪心合并，**仅当第一行总宽 ≤ 屏宽 1/3** 才并入（`ClockSurface.axaml.cs:354`）；提醒面板最大宽 2/3（`:353`）。
- 预警始终在提醒面板，不并入第一行；无天气时由倒计时顶位。
- 弹幕：文本超宽才滚动，速度 100px/s，点击=滚完当前遍+至少再一遍。

### 5.4 地震预警
反射外部「地震预警」插件（GUID `B27C0AF3-…`，`EarthquakeNotificationProvider`），读 `EarthquakeInfo` 属性、按参数个数挑 `GetIntensity` 重载，失败退本地经验公式（`Services/EarthquakeReader.cs:29-35,62-114,161-189`），每秒调用。弹出时整墙套 `BlurEffect` + 380ms `CubicEaseOut` 横向展开，卡片用 `FrostedCardBackdrop` 自绘磨砂。

### 5.5 背景图与玻璃
导入即复制副本 → 纯字节解析文件头（PNG/JPEG/GIF/BMP/WebP）→ 按「绝不放大 + 1.25× 像素预算」解码 → 生成清晰位图 + 模糊副本 + 两份 `uint[]` 像素快照 → 主题亮度（48px 缩略图取一个标量）二选一变体 → 光照/明暗 → 分块烘焙折射位图（仅 Liquid 档）→ 每帧合成。

### 5.6 托盘 / 设置 / 自动触发
- 托盘：`TrayMenuService` 直接改 CI `MainTaskBarIcon.Menu`（不走 `MoreOptionsMenuItems`），保证菜单项幂等补注册。
- 设置：任意属性变更 → 400ms 防抖 → `ConfigureFileHelper.SaveConfig`；右栏预览把**同一个 `ClockSurface`** 塞进 `Viewbox`，`DataContext` 是单例 VM，`IsPreview` 关掉写回/弹幕等副作用，200ms 防抖刷新。
- 自动触发：`AutoTriggerService` 订阅 `OnClass`/`OnAfterSchool`/`CurrentTimeStateChanged`，上课且课程匹配目标课程 → `Show()`，否则可见则 `Hide()`；放学 → `Hide()`；课间不动。

## 6. 三个核心机制拆解

### 6.1 CPU 液态玻璃（为什么不是着色器）
Avalonia 11 公开 `DrawingContext` 没有 `PushEffect`/自定义着色器（`Helpers/LiquidGlassBaker.cs:91-94`），所以：

- **不是实时特效**：只在「换图/换模糊半径/换档/换主题色/改参数/调明暗/布局变化」等离散时刻重算，每帧只合成预烘小位图。
- **按块烘焙**：12 个 `GlassTarget`（时钟 `Inset 16/8/Radius 16`，其余 `12/6/12`）各自一张 BGRA8888 预乘小图；整屏 8MB 位图被拆成几十 KB 的块——这是化解 CI **1.40 GiB 内存看门狗**的核心（`Views/BackdropLayer.cs:69-74,1029-1082`）。地震卡片刻意不登记（会盖住时钟），由 `FrostedCardBackdrop` 自绘。
- **同一套映射**：清晰背景、磨砂裁块、卡片磨砂、折射采样四处共用 `BackgroundImageMap.ComputeDestRect`/`MapToImage`（`Models/BackgroundImageMap.cs:20-23,40,81`；调用点 `Views/BackdropLayer.cs:266,521,624,1007-1020`）——玻璃里外严丝合缝是结构性保证，不靠调参。
- **逐像素算法**（`Helpers/LiquidGlassBaker.cs:107-283`）：`RoundedRectSdf` 抗锯齿 → SDF 梯度当法线 → 折射带内 `CircleMap` 推弯采样 → R/B 通道按 `Dispersion=0.04` 错位做色散 → 边缘 Frost 增强 → 上厚下薄材料色 → 斜面受光（`LightAngle=128°`, `BevelLight=0.35`）→ 3 抽头高斯近似镜边高光（宽 `2*scale`，强度 0.5，falloff 5）。关键参数：折射带 22·scale、位移 48·k·scale、`TintAlpha=opacity/100*0.8`、`RimFrost=0.35`。
- **三级脏区**：整图重建（换图/半径/是否模糊，容差 `max(8, a/50)` 像素预算）→ 光学参数版本号 `_contentVersion++` → 单块 `NeedsBake` 六项比对（`BakedRect/BakedVersion/BakedScale/Radius` 等）。全部经 120ms 防抖 `MarkGlassDirty`；拖动滑块期间一次都不烘，只画 2px 范围框。
- **渲染期硬防御**：`_inRenderPass` 守卫 + `Dispatcher.Post` 延后 `InvalidateVisual`，避免 CI 判「渲染期非法」并自动禁用插件（`Views/BackdropLayer.cs:234-243,493-501,1308-1310`）。
- **四级采样回退**（`LayerBackdrop`，`:1113-1171`）：图内 → Fit 留白虚化填充 → 主题底色 → veil 明暗；手写双线性必须反预乘（`:1174-1215`）；`OffsetSampler` 用整数设备像素偏移保证「分块烘」与「整层烘」逐像素等价（`Helpers/OffsetSampler.cs:8-16`）。

### 6.2 背景图管线
- 导入：复制到插件目录（时间戳命名 + 临时文件原子改名 + 最后删旧图，`Models/BackgroundImageStore.cs:36-67`）。
- 解码：先 `ImageHeader.ReadSize` 认格式，认不出 → **按屏宽放大解码**（老路，正是 1.40 GiB 事故来源），见风险 R2；`DecodeSize` 绝不放大 + 1.25× 像素预算（`Models/BackgroundImageMap.cs:125-153`）。
- 模糊：纯 CPU `StackBlur`（`RenderTargetBitmap` 后台渲染会抛异常），半径按 `imageSize/dest` 比例换算（旧写法按宽度比导致 GB 级内存），上限 `MaxRadius=88`；半径取整为 0 时返回未模糊副本 → 磨砂档会露出清晰图。
- 拉伸三档 `FillCrop/Fit/Stretch` 全走同一个 `ComputeDestRect`。
- 预加载：目标课前 2 分钟 `BackdropPreloadService`（20s 轮询、缓存 10 分钟、烘完强制 GC），单槽缓存（`TryTake` 取走即摘）。

### 6.3 主题：两槽位 + 哨兵
不是算法生成调色板，而是**两套写死 21 色调色板**（`Models/ClockTheme.cs:115-169`）+ 用户 6 色按变体存 `LightColors`/`DarkColors`，靠 `AppliedPaletteVariant` 与 `VariantUnknown=-1` 哨兵保证「切主题不丢自定义色、老配置升级不变样」（`Helpers/ClockThemeApplier.cs:19-24,60-67`）。命名陷阱：`VariantLight` = 浅玻璃 + 黑字，用于**暗**背景，与「背景亮暗」相反。明暗自动识别用 48px 缩略图取一个标量亮度（`BackgroundTone`），二选一变体。

## 7. 工程亮点

1. **不靠着色器做出可信的液态玻璃**：CPU 逐像素折射 + 色散 + 镜边高光 + 磨砂兜底（可读性滑块），并在注释里写清「为什么必须 CPU」。
2. **把内存事故变成架构约束**：按块小位图 + 块级 stale 校验 + 复用 `Canvas` + 整数设备像素偏移，直接用 1.40 GiB 看门狗事故反推设计。
3. **「同一套映射」的结构性正确**：玻璃内外的对齐由共用纯函数保证，而不是五处各自调参。
4. **渲染期非法标脏的防御**：`_inRenderPass` + 延后通知，避免 CI 把插件判故障自动禁用（并留下事故注释）。
5. **硬件生命周期绑定可见性**：麦克风/摄像头只在 `Show()` 开，隐藏/最小化/关闭全关，避免后台偷录。
6. **同一份 UI 同时做全屏与预览**：设置页右栏就是真身塞进 `Viewbox`，`IsPreview` 关副作用——预览永不与实机走样。
7. **噪音「段」语义完整**：起算底线、回落窗口、占比判定、每段至多一次、切课清零，比「超阈值就 +1」专业得多。
8. **防御性构建**：麦克风看门狗重连、摄像头 MF 活动监视器、预烘失败隔离、玻璃逐块异常隔离。
9. **详尽的中文事故注释**：把线上崩溃/被禁用/内存爆的历史写进代码，是这份代码最稀缺的资产。
10. **架构清晰**：Views/ViewModels/Models/Services/Helpers/NoiseDetection 分层规整，DI + HostedService 用法正确。
