# 13 · 开屏动画重演、退出淡出与动画速率（2026-11-07）

回应 m02367：

> 除了第一次有细微的动画，后面的全都看不见，你这直接闪现出来的；
> 把这个修了之后加上淡出动画，并把动画速率放进设置中。

## 1. 问题：只有第一次有动画，之后直接闪出

复现路径：第一次进入大屏时钟 → 有开屏过渡；退出后再进入 / 从任务栏点回 → 背景与画面直接出现，没有压暗截图、没有交叉淡入、也没有推近。

## 2. 根因

两件事叠加：

1. `Views/ClockSurface.axaml.cs` 里 `_introPlayed` 在第一次演完后置 `true`，此后再调用 `PlayIntroAsync` 直接 `return`；
2. 开屏只挂在 `SetupBackdrop()` 的 `Loaded += async (_, _) => await PlayIntroAsync();` 上——窗口 `Hide()` 再 `Show()` 复用的是同一个控件树，`Loaded` 不会再触发。

于是「第一次以外」既没有重演、也没有新的截图，窗口直接把已经套好静态值的背景画出来，看起来就是闪出。

## 3. 改动

### 3.1 每次显示都重演，截图提前到 Show 之前

- `Views/ClockSurface.axaml.cs`
  - 删除 `Loaded` 上的开场触发与 `_introPlayed`，改为公开方法 `BeginIntro(Bitmap? priorScreenshot)`；
  - `_introRunning` 防重入；组件层淡入时长 = `520ms ÷ 动画速率`。
- `Views/FullScreenClockWindow.axaml.cs`
  - `BeginBackgroundIntro(Bitmap?)` 转发给 `ClockSurface`；
  - 在 VM 显示窗口后调用。
- `ViewModels/FullScreenClockViewModel.Lifecycle.cs`
  - 首次显示：`_window.Show()` **之前**先 `ScreenCaptureService.CapturePrimaryScreen(0.45)` 拍干净桌面，Show 之后 `BeginBackgroundIntro(shot)`；
  - 最小化后点回复原：同样先拍、Show、再重演；
  - 这样第一拍一定是「压暗掉的原来画面」，不会把大屏自己截进去。
- `Views/BackgroundLayer.axaml.cs`
  - `PlayIntroAsync(settings, onTargetReveal, Bitmap? priorScreenshot = null)`：优先用调用方传入的截图，没有才补拍；
  - 窗口刚 Show 时视觉树可能还没接上（`_attached` 要等 layout），入口处最多等约 480ms（30×16ms）再接，避免「第一次调用直接 return」把动画吞掉。

### 3.2 退出淡出

- `Views/FullScreenClockWindow.axaml.cs` 新增 `HideWithFade(int durationMs)`：16ms `DispatcherTimer` 把窗口 `Opacity` 1→0（smoothstep `t²(3-2t)`），淡完 `Hide()` 并把 `Opacity` 复位成 1，下次显示从头来；
- 新增 `CancelHideFade()`：淡出途中又触发显示时取消淡出、复位透明度，避免「刚叫回来又被藏掉」；
- `ViewModels/FullScreenClockViewModel.Lifecycle.cs` 的 `Hide()` 改为 `HideWithFade(480 ÷ 动画速率)`，服务/定时器照旧立刻停（淡出期间画面是静态的，不需要继续采集）。

### 3.3 动画速率进设置

- `Models/PluginSettings.cs` 新增 `AnimationSpeed`（0.5~2.0 倍，默认 1.0，越大越快），持久化到 `Settings.json`；
- 影响：开屏截图停留（420ms）、背景交叉淡入（520ms）、壁纸推近（与淡入同长）、组件淡入（520ms）、退出淡出（480ms）；统一 `Scaled(baseMs, speed) = max(16, round(baseMs / speed))`；
- 设置页「外观」页背景分组下新增 `动画速率` 一行（Slider 0.5~2.0，步长 0.05，右侧显示 `1.00×`），绑定 `SettingsPage.Background.cs` 的 `AnimationSpeed` / `AnimationSpeedText`。

### 3.4 推近更明显

壁纸推近起点从 `zoom - 0.10` 改为 `zoom - 0.15`（默认 1.15 → 从 1.00 推到 1.15），配合可调速率，肉眼更容易看出「镜头推进」。

## 6. 已知限制 / 待真机验收

- 本机没有 ClassIsland 宿主，动画观感、截图内容、与课表栏的层叠需要真机过一遍；
- 截图失败（HDR/DRM/远程桌面）时仍会退化成「直接显示背景 + 组件淡入」；
- 若窗口显示后的首帧超过约 480ms 才接上视觉树，该次开屏会退化为直接显示；
- 退出淡出期间窗口已不可交互，但仍在屏幕上约 0.5s（按速率浮动）。
