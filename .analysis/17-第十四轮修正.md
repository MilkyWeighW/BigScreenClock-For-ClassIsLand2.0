# 第十七轮：压暗动画、组件字号统一、音量条收窄、按钮图标化

日期：2026-11-07

这是第十四轮用户反馈的四条：

1. 为「压暗」也启用动画；
2. 除时钟、音量等组件外的其它组件默认字体统一并对齐；
3. 音量条短一些；
4. 右下角最小化 / 退出简化为纯图标。

## 1. 压暗动画

### 现象与根因

开屏过渡原本是「截图时就把画面乘 0.45 压暗」，截图出炉就是满压暗，第一帧直接黑一下——
背景、组件都有过渡，唯独「压暗」是硬切。

### 实现

- `Views/BackgroundLayer.axaml` 新增 `IntroVeil`（黑色 Border，`Opacity=0`），夹在
  `PriorImage`（旧画面）与 `TargetImage`（目标画面）之间：只盖截图，不挡后来的背景。
- 开屏改为：截图原样显示 → `IntroVeil` 在 280ms（按动画速率缩放）内淡入到 0.45 →
  目标背景交叉淡入时 `IntroVeil` 与 `PriorImage` 一起淡出。
- 两类背景的节奏靠 `IntroDimFadeMs` 统一：壁纸类型总停留仍是 `ScreenshotHoldMs=420`，
  其中前 280ms 是压暗淡入；纯色 / 自定义图也至少等压暗演完再换背景。
- `ScreenCaptureService.CapturePrimaryScreen(0.0)`：截图不再预压暗（`ViewModels/FullScreenClockViewModel.Lifecycle.cs`
  两处调用同步改），压暗完全由背景层承担，才能动画。
- `PrepareForIntro()` / `FinishImmediately()` 同步把 `IntroVeil` 的过渡清掉、透明度归零，
  避免复用窗口时第二次开屏出现「淡出残留」。

## 2. 组件默认字号统一

### 实现

- `Views/ClockSurface.axaml` 顶部加两个资源：

  | 资源 | 值 | 用于 |
  | --- | --- | --- |
  | `ComponentFontSize` | 24 | 日期、天气、降雨、倒计时、文本、预警详情、提醒面板正文 |
  | `ComponentSecondaryFontSize` | 16 | 各块正下方的颜文字 / 副标题 |

- 原来散落的 20 / 12 / 16 全部换成资源引用，之后想整体调大调小只改这两个数。
- 时钟与音量条不在此列：时钟跟「时钟字号」，音量条标题/档位保持 20。
- `Models/PluginSettings.cs`：课程信息默认字号 `30 → 24`，与 `CountFontSize=24` 同档。
- `Models/ReminderData.cs`：预警条目默认字号 `15 → 16`（与二级字号一致；摄像头提醒可调范围仍是
  16~19）。
- `ViewModels/FullScreenClockViewModel.ReminderLayout.cs`：第一行合并判定的宽度估算同步从
  19/16 改成 24/24、图标 20→24，否则字号变大后「能不能并进第一行」的判断会比实际偏松。

## 3. 音量条收窄

- `Views/ClockSurface.axaml` 去掉 `Width="{Binding #ClockText.Bounds.Width}"`，改为占位 600。
- `Views/ClockSurface.axaml.cs` 新增 `VolumeBarWidthRatio = 0.72`，在 `ApplyBodyPositions()`
  里按时钟文字实测宽度乘比例设 `VolumePanel.Width`；值没变不赋值，避免 SizeChanged 自激。
- 时钟字号改变时音量条跟着变宽变窄，仍然居中，只是不再和时钟等宽。

## 4. 按钮图标化

- `MinimizeButton` / `ExitButton` 去掉「最小化」「退出」文字，只留 18px Fluent 图标
  （`&#xF09D;` / `&#xE671;`），`Padding="10,6"`、`ToolTip.Tip` 保留说明，`x:Name` 与 `Click` 不变。

## 已知限制

- 压暗淡入与壁纸推近共用同一条时间轴，若把动画速率调到 2.0×，280ms 会缩短到 140ms，
  压暗会更接近「闪一下」；需要更慢可把速率调小。
- 字号资源只作用于 `ClockSurface.axaml` 内的硬编码文字；绑定的字号（时钟/课时/计数/预警条目）
  仍由各自设置项控制。
