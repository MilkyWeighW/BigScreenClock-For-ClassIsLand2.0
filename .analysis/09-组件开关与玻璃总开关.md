# 09 · 组件开关、组件条与「显示组件玻璃」全局开关

> 对应需求（m01190 / m01192 / m01193）：组件要有启用开关；「组件」页签顶部要有 ClassIsland「主界面 > 组件」那样的横向组件条，只显示已启用的组件，点谁就配谁；组件的先后决定大屏上同区内谁排前；组件外围那层用来渲染液态玻璃/折射的东西，改成一个全局开关。
> 澄清结果：分区流式（顶部行 / 主体 / 底部行各自排，不跨区）；排序 UI = 拖拽 + 左右箭头；全局玻璃开关放在「外观」页。

## 1. 交互模型

```
设置页「组件」页签
  ├─ 说明文字
  ├─ 组件条（横向 ListBox，只列已启用）
  │     └─ chip：图标 + 名称；拖拽换位；点击选中
  ├─ ＋ 添加组件（Flyout 列未启用；全启用时给空态提示）
  └─ 选中组件设置（SettingsExpander）
        ├─ Footer：启用 ToggleSwitch ｜ 恢复默认
        └─ 子项：大小(0.5×~2×) / 水平位置(-50%~50%) / 垂直位置 / 顺序（←前移 / →后移，显示「第 N 个」）
```

大屏侧对应关系：

- **启用**：关闭后组件不渲染、也不占位（隐藏的是 `ComponentHost` 外壳，整块从布局里消失）。
- **顺序**：只在同一分区内生效。顶部一行（天气 / 降雨 / 倒计时 / 文本）真的会换位；主体区按顺序决定时钟与音量条谁在上；预警详情（居中）、日期（靠右）、计数（靠左）、课程（居中）这些各自钉住锚点，顺序只影响它们在设置页列表里的位置。默认全部未排序时按 `ComponentCatalog.All` 的清单顺序，视觉与改造前一致。
- **大小 / 位置**：换算成 `RenderTransform` 的缩放与像素位移（偏移单位 = 大屏宽/高的百分比）。`RenderTransform` 不参与布局，所以不会把邻居顶走；全默认时 `RenderTransform = null`，与改造前逐像素一致。

## 2. 数据模型

`Models/ComponentLayout.cs`

| 成员 | 默认 | 说明 |
| --- | --- | --- |
| `Scale` | 1 | 0.5 ~ 2.0 |
| `OffsetX` / `OffsetY` | 0 | 大屏宽 / 高的百分比，-50 ~ 50 |
| `Enabled` | true | 关掉后不渲染不占位，大小/位置值保留 |
| `Order` | null | null = 按组件清单顺序；同区内小者在前 |

`ComponentCatalog.All` 仍是 13 项：clock / date / weather / rainMerge / countdownMerge / textMerge / alertDetail / reminderPanel / volume / counter / course / progress / earthquake。`Reset()` 只重置大小与位置，不动启用与顺序。

`Models/PluginSettings.cs`

- `Dictionary<string, ComponentLayout> ComponentLayouts`：setter 会订阅/退订每份布局；任何一份布局属性变化 → 冒泡 `ComponentLayoutsChanged` + `OnPropertyChanged(nameof(ComponentLayouts))`，于是 **400ms 防抖存盘会把组件改动写进 Settings.json**，大屏侧也能收到同一个通知。
- `bool ShowGlass`（默认 true）：外观页「显示组件玻璃」。

## 3. 大屏侧实现

### 3.1 `Views/ComponentHost.cs`

`ComponentHost : ContentControl`，只做两件事：

1. 模板 = `ContentPresenter`（没有任何装饰性外框/底色——那层「外围的东西」已按用户要求收回成全局开关）；
2. `OnAttachedToVisualTree` 找到祖先 `ClockSurface`，按 `ComponentId` 取 `Plugin.Settings.GetComponentLayout(ComponentId)` 订阅，`Apply()` 里把 `Scale/OffsetX/OffsetY` 换成 `MatrixTransform`。

显隐与排序由 `ClockSurface` 统一做：组件开关要和 VM 的显示条件（有没有天气、提醒面板开不开、音量条显不显示……）合在一起算，还要动兄弟控件的顺序，放在外壳里做会变成两处逻辑打架。

### 3.2 `Views/ClockSurface.axaml`

13 个元素全部包进命名宿主：`WeatherHost / RainHost / CountdownHost / TextHost / AlertDetailHost / DateHost / ClockHost / VolumeHost / CounterHost / CourseHost / ReminderPanelHost / ProgressHost / EarthquakeHost`；原来挂在宿主上的 `IsVisible` 绑定统一删除（显隐改由代码算），内层控件的绑定与 `x:Name` 一字未动。顶部四块共处的 `StackPanel` 命名 `TopMergeFlow`，供排序换位用。

### 3.3 `Views/ClockSurface.axaml.cs`

- `ApplyComponentVisibility()`：`host.IsVisible = 启用 && 该组件此刻的显示条件`。时钟/日期/计数没有额外条件；其余按 VM：`ShowWeatherInFirstRow` / `ShowRainMergedInFirstRow` / `ShowCountdownMergedInFirstRow` / `ShowTextMergedInFirstRow` / `HasExpandedAlert` / `ShowDecibelMeter` / `ShowCourseInfo` / `ShowReminderPanel` / `ShowCourseProgress` / `ShowEarthquakeAlert`。
- `ApplyComponentOrder()`：把顶部四块按 `EffectiveOrder`（`Order ?? 清单索引`）排序后用 `Children.Move` 重排；末尾重新摆位。
- 触发点：`DataContextChanged` / `Loaded` / `PluginSettings.ComponentLayouts` 通知 / 上述 VM 属性变化。
- 玻璃：`ApplyBackdrop()` 里档位改为 `on && settings.ShowGlass ? GlassMode : Off`——**关掉后所有组件的玻璃 / 模糊 / 折射都不画，文字直接叠在背景上**；地震提醒的整屏磨砂不受影响。组件被隐藏时玻璃会自动消失（`BackdropLayer.ComputeGlassRects` 本来就跳过不可见目标），隐藏/显示会重新登记脏区。
- `ApplyBodyPositions()`：时钟与音量条谁在上由 `EffectiveOrder` 决定。默认（时钟在前）与改造前逐像素一致；把音量条拖到时钟前面后镜像：音量条贴顶、时钟被压到它下面。滑块的可用范围也按当前顺序各自计算。
- 位置写回加了保护：**组件被关掉时不写回**，否则关着的那块会把自己的坐标压到 0 附近，再打开时用户拖好的位置就丢了。

## 4. 设置页实现

- `Settings/SettingsPage.Components.cs`（421 行）：
  - 集合 `ComponentItems` / `EnabledItems` / `DisabledItems`，选中态 `SelectedComponent`，辅助 `HasSelectedComponent` / `HasEnabledItems` / `HasDisabledItems` / `SelectedOrderText`；
  - 排序键 `EffectiveOrder = Layout.Order ?? CatalogIndex`，稳定排序；用户移动时才把 13 项 `Order` 规范成 0..12（老配置启动时保持 null，不写回）；
  - 启用项连续编号、禁用项按原相对顺序续号；选中项被关掉时自动跳到邻居；
  - 拖拽：`PointerPressed` 记起点、`PointerMoved` 超 6px 进入拖拽并高亮目标容器、`PointerReleased` 交换顺序；
  - Layout 生命周期比页面长，订阅集中在 `Loaded`/`Unloaded` 配对，避免设置页泄漏。
- `Settings/SettingsPage.axaml`（989 行）：「组件」页签替换为组件条 + 添加 Flyout + 选中设置；「外观」页签最前面新增「组件玻璃」分组与 `ShowGlass` 开关；其余四个页签与右侧 332 预览未动。
- `Settings/SettingsPage.Appearance.cs`：`ShowGlass` 属性（与 `PluginSettings.ShowGlass` 同源，ToggleSwitch 双向绑定）。

## 6. 已知限制

1. **缩放时玻璃不跟着缩放**：`BackdropLayer` 用 `Bounds` 算玻璃矩形、不含 `RenderTransform`；组件缩放后玻璃仍按原尺寸烘。位置移动跟得上（`TranslatePoint` 含布局位移）。用户已知悉，留作后续修。
2. 顺序目前只对顶部一行与「时钟/音量条」有可见效果；其余组件位置由既有锚点决定（按澄清时的 A 方案）。
3. 拖拽落点高亮色写死 `#3D0078D4`，未跟主题。
4. 把组件都关掉时大屏只剩背景与右下角两个按钮——这是开关语义的直接结果，未额外拦截。
