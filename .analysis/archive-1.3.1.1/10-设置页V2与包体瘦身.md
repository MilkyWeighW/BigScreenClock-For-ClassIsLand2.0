## 2. 设置项归属（统一到组件设置）

组件页里，选中某组件后除通用的「启用 / 大小 / 水平位置 / 垂直位置 / 顺序」外，还按 `IsXxxSelected` 显示专属行：

| 组件 | 专属设置 |
| --- | --- |
| 时钟 clock | 字号、字体颜色、主体区位置（高度百分比） |
| 音量条 volume | 标题文字颜色、位置（高度百分比） |
| 课程信息 course | 显示精确打铃时间、字号、颜色 |
| 吵闹计数 counter | 计数字号 |
| 进度条 progress | 进度条颜色 |
| 降雨提醒 rainMerge | 降水提醒颜色 |
| 提醒面板 reminderPanel | 显示颜文字、摄像头占用提醒（开关 / 要提醒的摄像头 / 刷新设备 / 提醒字号） |
| 地震警报 earthquake | 未装「地震预警」插件时的提示 |
| 日期 / 天气 / 倒计时 / 文本 / 预警详情 | 无专属设置（只有通用项） |

配套的数据层改动：

- **旧显示开关一次性迁移**：`PluginSettings.MigrateLegacyComponentVisibility()`（由 `Plugin.Initialize` 调用）在 `ComponentVisibilityMigrationVersion < 1` 时，把旧的 `ShowDecibelMeter` / `ShowCourseInfo` / `ShowNoisyCounter` / `ShowReminderPanel` / `ShowWeatherReminder` / `ShowAlertsReminder` / `ShowCountdownReminder` / `ShowTextReminder` / `ShowRainReminder` / `ShowEarthquakeReminder` 搬进对应组件的 `Enabled`，然后把旧开关置 `true`，版本号置 1。
  - 这样老用户「关掉过某个组件」的意图保留；大屏侧（`ClockSurface.ApplyComponentVisibility`）只看 `Layout.Enabled` + 数据条件，不再看旧开关。
- `SettingsPage.Components.cs` 新增 13 个 `IsXxxSelected` 与 `RaiseSelectionFlags()`，供专属行显隐。

## 5. 遗留与风险

1. **无真机可视化验收**：本机未安装 ClassIsland，多行组件条的实际换行、拖拽手感、专用行的展开顺序都需在宿主里点一遍。
2. **旧开关已无 UI**：`ShowDecibelMeter` 等属性仍保留在 `PluginSettings`（迁移时置真），如果以后要恢复「显示在/不显示」的独立开关，记得先想清楚和 `Enabled` 的关系。
3. **玻璃不跟随缩放**：组件缩放时玻璃矩形仍按 `Bounds` 计算（不含 `RenderTransform`），本轮未动，属已知限制。
4. **NAudio 后端裁剪**：若某天用到 ASIO/MIDI/WinForms 后端，需把对应 dll 从 `TrimCipxPayload` 的剔除列表里拿掉。
