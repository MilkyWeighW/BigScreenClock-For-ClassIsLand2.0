## 3. 跨任务接口（必须按这个签名交付）

- `bg`：
  - `Views/BackgroundLayer`：保持现有 `Apply(PluginSettings, bool isPreview)`；新增 `public bool NeedsTransparentWindow { get; }`（NativeBlur/WebPage 时为 true）。
  - `Services/NativeBlur`：`static bool TryEnable(IntPtr hwnd, bool enabled, uint abgrTint = 0x00000000)`（内部用 `SetWindowCompositionAttribute`，失败返回 false，绝不抛）。
  - `Services/WebView2Availability`：`static bool IsAvailable { get; }`、`static string? Version { get; }`、`static string UnavailableReason { get; }`（探测注册表 + `CoreWebView2Environment.GetAvailableBrowserVersionString()`，全程 try/catch）。
  - `Services/WebBackgroundService`：`void Attach(Avalonia.Controls.Window clockWindow)`、`void Detach()`、`void Sync(PluginSettings settings)`（按 `BackgroundKind == WebPage` 显示/隐藏下层窗口并导航 `BackgroundWebUrl`；不可用时静默隐藏）。
  - `Settings/BackgroundExtrasPanel`：无参 UserControl，自己从 `Plugin.Settings` 取数据；负责网页地址、实时模糊说明、WebView2 可用性提示（不可用时置灰）。Lead/ui 只负责把它放进设置页。
- `components`：
  - `Views/ClockSurface` 新增 DP：`SurfaceDesignWidth`/`SurfaceDesignHeight`（double，默认 1920/1080，仅供预览宿主用来算布局），以及只读属性 `ContentLayer`（组件层，供调试/截图，可选）。
  - `Settings/ComponentStylePanel`：无参 UserControl，选中组件后显示长宽比（StretchX/StretchY）、字体族/字号/字重、文字材质。`Settings/StickerPanel`：无参 UserControl，管理 `Plugin.Settings.ImageInstances`（添加/删除/选图/填充方式）。
  - 贴纸渲染：每个 `ImageInstance` 一条，id = `instance.ComponentId`，各自套 `ComponentHost`，**不要**再共用单一 `ImageHost`。
- `ui`：
  - 预览：`PreviewWidth/PreviewHeight = 屏幕逻辑尺寸 × PluginSettings.PreviewRenderScale`；`ClockSurface` 用 `Width={Binding PreviewSourceWidth} Height={Binding PreviewSourceHeight}` + `LayoutTransform=ScaleTransform(0.4)`，再放进 Viewbox。新增 `PreviewSourceWidth/Height` 属性（= 屏幕逻辑尺寸，供上面两个绑定）。
  - 在合适位置插入 `BackgroundExtrasPanel` / `ComponentStylePanel` / `StickerPanel`（命名空间 `LargeScreenClockRevived.Settings`，与 SettingsPage 同）。不实现它们内部逻辑。
  - 新增「显示与 ClassIsland 重合的组件」入口：把 `date/weather/countdownMerge` 三个布局的 `Enabled` 重新打开（组件页签里已有启用开关，可只加一句说明）。
- `platform`：
  - `Services/SettingsStore`：`static Task<PluginSettings?> LoadAsync(string path)`、`static Task SaveAsync(string path, PluginSettings settings)`，内部 `await Task.Delay(10)` 后在线程池做 IO（不阻塞 UI）。`Plugin.SaveSettings()` 改为触发异步保存（保留同步签名）。
  - `Services/CiTimeService`：`DateTime Now`（优先 CI `IExactTimeService`，失败回退 `DateTime.Now`）。
  - `Helpers/CiThemeReader`：`static string? TryReadAccentColor()`（反射 CI 主题服务/资源，失败返回 null）。
  - ViewModel：显示时间改用 `CiTimeService.Now`；主题色跟随 `FollowClassIslandAccent`；顺手修掉每次刷新 new 画刷/重复读盘等热点（见清单 6/13）。
