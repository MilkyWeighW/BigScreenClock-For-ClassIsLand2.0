# 第十八轮：组件不透明度 + 「自定义图片」组件

回应 m03556 两条功能请求（另附「各组件样式位置」对照表，见 §4）。

## 1. 所有组件加「不透明度」

- `Models/ComponentLayout.cs`：新增 `Opacity`（0~1，默认 1），与 `Scale/OffsetX/OffsetY` 一起存进
  `PluginSettings.ComponentLayouts`，`IsDefault` 判断与 `Reset()` 一并纳入。
- `Views/ComponentHost.cs`：`Apply()` 里把 `Opacity = layout.Opacity` 设在组件外壳上——
  文字、图标、进度条会一起变淡，且**不是**变换，不会影响布局。
- 设置页：组件页 → 选中任意组件 → 「不透明度」滑块（0%~100%，步进 1%），
  位置在「大小 / 水平位置 / 垂直位置」之后、「顺序」之前。
- 语义：0% 只是看不见，**位置照旧占着**（组件布局不重排），这样拖回去时不会整屏跳一下。

## 2. 新增「自定义图片」组件

- `Models/ComponentLayout.cs` 的 `ComponentCatalog.All` 新增 `image`（名字「自定义图片」，
  图标 `ic_fluent_image_20_regular` = `\uE9B2`）。已存在的配置启动时由
  `PluginSettings.EnsureComponentLayouts()` 自动补上这份布局。
- 设置项（`Models/PluginSettings.cs`）：
  - `CustomImageFile`：配置目录里的副本文件名，空 = 没选图；
  - `CustomImageStretch`：0 完整显示 / 1 铺满裁切 / 2 拉伸。
- `Models/ComponentImageStore.cs`：选图时把原图**复制一份**进插件配置目录
  （`component-image-<时间戳>.<ext>`，先写 .tmp 再改名，失败不删旧图），
  设置里只记副本名；和背景图的 `background-*` 前缀分开，互不覆盖。格式用 `ImageHeader` 校验。
- 大屏（`Views/ClockSurface.axaml` 的 `ImageHost`，挂在主体区 `BodyArea` 里）：
  - 默认贴主体区右侧、垂直居中（`Margin="0,0,40,0"`）；
  - 基准宽度 = 屏幕宽 × 30%，保持原图长宽比；高度超过屏幕 60% 时按高度反算；
  - 再大的只能靠组件的「大小倍率」（0.5~2.0）放大，位置用组件的水平/垂直偏移微调；
  - 没有图 / 图读不出来时整块隐藏（`_customImageAvailable`），不留空壳；
  - 换图时旧位图延后一帧再 `Dispose`，同图不重复解码（拖滑块不会卡）。
- 设置页：组件页选中「自定义图片」后出现两行——「图片」（摘要 + 选择图片 + 清除）
  与「图片填充方式」。

## 6. 已知限制

- 图片基准宽度固定为屏宽 30%，想要更大只能靠「大小倍率」（上限 2×），
  竖长图会被 60% 高度上限压小；小图放大后可能糊。
- 图片组件目前只有「填充方式」一个专属选项，没有圆角/边框（需要可加）。
- 不透明度为 0 时组件仍占位，这是刻意的（位置不跳）；若想要「0 = 当作关闭」，需另加语义。
- 旧配置里没有 `image` 那份布局，启动后自动补一份默认（启用、无图 → 大屏上不显示）。
