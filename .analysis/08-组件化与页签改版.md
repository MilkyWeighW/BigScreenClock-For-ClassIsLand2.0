# 第四轮：设置页页签化 + 大屏元素组件化

日期：2026-11-06

## 1. 需求（用户原话要点）

1. 设置页要像 ClassIsland「提醒」页那样**横向并列分组**（即顶部 `TabControl` 页签），右栏预览保持常驻；
2. 「自定义背景」在设置页里**打不开/不可用**；
3. 把大屏上显示的所有元素（除背景层与右下角最小化/关闭）**解耦为组件**，每个组件的外框与底色可开关
   （用户已知会让液态玻璃失效，本轮先做开关，玻璃跟随后续再修）；
4. 每个组件单独设置**大小与位置**，没有配置时 fallback 到默认值；
5. 组件区仿照 ClassIsland「主界面 > 组件」页，放进上面那个横向分组里。

## 3. 「自定义背景不可用」的根因与修复

根因不是图片格式：`Models/ImageHeader.cs` 支持 PNG/JPEG/GIF/BMP/WebP，第二轮 R3 后
「认不出的格式」会直接抛错并给出提示，正常图片不会被挡。

真正的原因是一处**自锁**：外层「自定义背景」`SettingsExpander` 自己绑了
`IsEnabled="{Binding BackgroundEnabled}"`，而 `BackgroundEnabled` 默认 `false`
（开关就在这个 `Expander` 的 `Footer` 里）——整个 `Expander` 连同它的开关一起被禁用，
用户永远点不到那个开关。修复：删掉该 `IsEnabled` 与同处多余的 `Opacity`，
内部子项与全部绑定保留（`Footer` 的 `ToggleSwitch` 现在才是唯一入口）。

## 4. 组件模型

### 4.1 新增文件

`Models/ComponentLayout.cs`

- `ComponentLayout : INotifyPropertyChanged`：`Scale`（0.5–2，默认 1）、
  `OffsetX`/`OffsetY`（−50–50，单位 = 大屏宽/高百分比，默认 0）、
  `ShowFrame`/`ShowBackground`（默认 `false`）、`IsDefault`（算出来的，`[JsonIgnore]` 不存盘）、`Reset()`；
  值走 `Set<T>`，相等不触发 `PropertyChanged`。
- `ComponentDescriptor(string Id, string Name, string Description, string Glyph)`：只描述「有哪些组件」，不存盘。
- `ComponentCatalog.All`：13 个组件，顺序 = 设置页顺序 = 大屏从上到下：
  `clock` 时钟 / `date` 日期 / `weather` 天气 / `rainMerge` 降雨（顶部）/ `countdownMerge` 倒计时（顶部）
  / `textMerge` 文本（顶部）/ `alertDetail` 预警详情 / `reminderPanel` 提醒面板 / `volume` 教室音量
  / `counter` 吵闹计数 / `course` 课程信息 / `progress` 课程进度条 / `earthquake` 地震警报。
  背景层与右下角「最小化 / 退出」按钮**不在**清单里（背景是整屏底，按钮跟着窗口走）。

`Views/ComponentHost.cs`

- `ComponentHost : ContentControl`，`ComponentId` 决定读哪一份布局；模板用 `FuncControlTemplate` 手搭三层：
  半透明黑底色（`#33101010`，圆角 10）→ `ContentPresenter` → 橙色外框（`#B0FF9800`，1px，圆角 10），
  外框/底色都不吃鼠标事件。
- `OnAttachedToVisualTree` 时向上找 `ClockSurface` 拿大屏尺寸、订阅 `SizeChanged`，并订阅该组件的 `ComponentLayout.PropertyChanged`；
  脱离可视树时全部退订。
- 应用方式：`RenderTransform`（`RenderTransformOrigin=Center`）——
  `Matrix.CreateScale(s) * Matrix.CreateTranslation(dx, dy)`，`dx = OffsetX/100 * 大屏宽`，`dy = OffsetY/100 * 大屏高`。
  **全默认（1 / 0 / 0）时直接 `RenderTransform = null`**，与改造前逐像素一致。
- 为什么用 `RenderTransform`：这面墙是绝对定位叠层，改 `Margin`/布局会顶走邻居；
  `RenderTransform` 只改变绘制位置，时钟/音量条那套「上下限位」求解（`ApplyBodyPositions`）一个字节都不用动。

### 4.2 设置持久化

`Models/PluginSettings.cs` 新增：

- `Dictionary<string, ComponentLayout> ComponentLayouts`（存进 `Settings.json`，setter 里 null 兜底）；
- `GetComponentLayout(id)`：缺项补一份默认值并放回字典（老配置升级后自动获得默认值）；

### 4.4 代码后置：`Views/ClockSurface.axaml.cs`

- 主体区的定位求解改为对宿主操作：`clockHeight = ClockHost.Bounds.Height`、
  `volumeVisible = VolumeHost.IsVisible`、`volumeHeight = VolumeHost.Bounds.Height`、
  `SetTop(VolumeHost, …)` / `SetTop(ClockHost, …)`；并订阅 `ClockHost`/`VolumeHost` 的 `SizeChanged` 重算。
- 玻璃登记（`SetupBackdrop` 的 12 个 `GlassTarget`）仍是**内层控件**（玻璃只认具体内容块），
  但 `Bounds`/`IsVisible` 监视列表追加了 `ClockHost, VolumeHost`——因为内层 `Bounds` 不再随位置变化，位置变化发生在宿主上。

### 4.5 设置页「组件」页签

`Settings/SettingsPage.Components.cs`：`ObservableCollection<ComponentSettingItem> ComponentItems`，
`InitializeComponentItems()` 按清单每项生成一行（`Descriptor` + `Layout` + `IconSource = new FluentIconSource(glyph)`），
`ResetComponent_Click` 把该行布局 `Reset()`。

页签内：一行说明 + `ItemsControl`，每行 `SettingsExpander`（图标/名称/说明 + Footer「恢复默认」按钮）
展开后是 5 个 `SettingsExpanderItem`：

- 大小：`Slider 0.5–2`（步进 0.05）双向绑 `Layout.Scale`，右侧显示 `{0:P0}`（如「125%」）；
- 水平 / 垂直位置：`Slider −50–50`（步进 5）绑 `Layout.OffsetX` / `Layout.OffsetY`，右侧显示百分比；
- 外框：`ToggleSwitch` 绑 `Layout.ShowFrame`；
- 底色：`ToggleSwitch` 绑 `Layout.ShowBackground`。

## 6. 已知限制（本轮有意不做）

1. **玻璃不跟随缩放**：玻璃按控件布局矩形（`Bounds` + `TranslatePoint`）从背景层裁块烘焙，
   位移能跟上（`TranslatePoint` 含变换），缩放不会——`Scale ≠ 1` 时玻璃仍是原尺寸。
   按用户要求先留开关，后续单独修。
2. **底色会盖住玻璃**：`ShowBackground` 的底色画在内容下面、玻璃上面，开了就看不见该块玻璃。
3. 组件位置以「大屏宽/高的百分比」平移，预览框里同样按百分比换算（预览尺寸小 → 位移像素小），
   视觉比例一致但不等于全屏像素值。
4. `ShowFrame`/`ShowBackground` 是纯视觉层，不参与命中测试（`IsHitTestVisible=false`），
   玻璃目标与鼠标事件仍落在原控件上。
