# 第十三轮：课程身份、图标/字号统一与壁纸缓存

用户反馈（2026-11-07）：

1. 上课初期保护仍从「打开大屏时钟」开始计时；
2. 开屏动画第一帧会先把完整界面渲染出来（闪一下）；
3. 规范统一组件默认字号，图标改用 Fluent；去掉默认弹出的那封信；
4. 精简 README 之后再把信加回来；
5. 「触发课程」按字符串识别，同名不同绑定的课程无法精细调整；
6. 大屏有微弱掉帧，可尝试预渲染模糊壁纸。

## 1. 上课初期保护改按课程真实开始时间

根因两处叠加：

- `OnTimeStateChanged` 上课分支是 `_classStartTime = LookupActualClassStart(subjectName) ?? NowVirtual`。插件自己解析的课表里按科目**名字**匹配，遇到同名科目 / 课表未解析到时返回 null，于是回退成 `NowVirtual`——正好是打开大屏那一刻。
- 打开大屏时课程已经开始，CI 的 `CurrentTimeStateChanged` 不一定立刻再发一次，`_classStartTime` 一直停留在打开时刻。

修复（`ViewModels/FullScreenClockViewModel.Course.cs` 等）：

- 新增 `LookupCiClassStart()`：直接问 CI 的 `ILessonsService`——`CurrentState == OnClass` 且 `CurrentTimeLayoutItem` 是上课项时，用 `DateTime.Today + CurrentTimeLayoutItem.StartTime` 得到课程真实开始时刻（`StartTime` 与插件 `NowVirtual` 同一时间域，时间偏移自动抵消）。这是最权威的来源，优于解析 JSON。
- `LookupActualClassStart(subjectName, subjectId)` 改为「先按时间窗过滤，再优先比 SubjectId、无 Id 才比名字」。
- `OnTimeStateChanged` / `IsInProtection()` / `Show()` / `ResumeFromMinimizePause()` 统一按
  `LookupCiClassStart() ?? LookupCurrentClassStart() ?? 已有的 _classStartTime` 取值，**不再回退成打开时刻**；三者都拿不到时宁可不做初期保护。

## 2. 开屏首帧不再闪出完整界面

新增「先藏内容层、等背景过渡到目标画面时再淡入」的链路：

- `Views/ClockSurface.axaml.cs`：`PrepareIntro()`（非预览时把 `ContentLayer.Opacity = 0`）。
- `Views/FullScreenClockWindow.axaml.cs`：`PrepareForIntro()` 转发。
- `ViewModels/FullScreenClockViewModel.Lifecycle.cs`：两处 `Show()` 分支在 `_window.Show()` **之前**调用 `PrepareForIntro()`，之后由 `BeginBackgroundIntro` 在目标画面淡入时把组件一起淡入。

## 3. 图标统一为 Fluent、字号规范化、去掉默认信件

- `Helpers/IconGlyph.cs` 改为把 Lucide 图标枚举/名字映射到 **Fluent** 字形（天气 10 种、沙漏、温度、警告、勾选、摄像头等），上游调用点（`CiWeatherReader`、`ReminderData`、音量档位片段）不变。
- `Views/ClockSurface.axaml`：三处动态图标 `TextBlock Classes="icon"` 换成 `<controls1:FluentIcon Glyph="{Binding ...}"/>`，删除 `TextBlock.icon` 样式与 `xmlns:cis`；`Views/AboutPopupWindow.axaml` 的标题图标也从 Lucide 换成 Fluent。连同先前已换的 7 处静态图标（task-19），大屏与关于弹窗上的所有图标都出自 Fluent 图标字体。
- 字号统一到偶数阶（12 / 16 / 20 / 24 / 30）：天气与提醒标题 19→20、副标题 11→12、日期 22→24、音量档位文字 18→20；`PluginSettings` 课程信息默认字号 28→30。时钟 180、计数 24 不变。
- 删除 `Views/LetterWindow.axaml(.cs)`、`SettingsPage.axaml.cs` 的 `ShowLetterIfNeeded()`、`PluginSettings.LetterDismissed`——设置页不再自动弹信。

## 4. README 精简并把信加回来

`README.md` 重写为：简介 → 功能（12 条短条目，含组件、背景、开屏过渡、一键重置）→ 环境要求 → 依赖表 → 构建与打包 → 版本号与 apiVersion → 离线构建 → **致所有用户的一封信**（1.2.0.0 起不再加新功能、致谢、sokumei 2026/10/31）→ 作者与许可。原文里冗长的参数解释保留必要信息、删去重复背景说明。

## 5. 触发课程改用 SubjectId

- `Models/PluginSettings.cs`：新增 `TargetCourseIds`（`ObservableCollection<string>`，存 `Guid` 字符串），`IsTargetCourse(name, subjectId)` 优先按 Id 命中；旧配置只有名字时仍走 `CourseMatch` 名称匹配（兼容老数据）。
- `Models/CiCourseIdentity.cs`（新）：`TryGetCurrentClassSubjectId(ILessonsService)` 从 `CurrentClassPlan.Classes` 里定位当前时段项（引用或起止时间匹配），返回 `ClassInfo.SubjectId`——CI 的 `Subject` 本身没有 Id，身份只存在于 `Profile.Subjects` 的 Guid 键与 `ClassInfo.SubjectId`。
- `Models/ClassStartSchedule.cs`：`Slot` 增加 `SubjectId`；`NextTargetStart` 的目标判定改为 `Func<string?, string?, bool>`，把 Id 一起传下去。
- `ViewModels/FullScreenClockViewModel.Course.cs`：`LoadTodaySchedule` 生成 `TimeSlot` 时一并记录 `Classes[ci].SubjectId`；`LookupCurrentClassSubjectId()` 供事件回调使用。
- `Services/AutoTriggerService.cs`：自动显示判定改为 `CiCourseIdentity.TryGetCurrentClassSubjectId(...)` + `IsTargetCourse(name, id)`。
- `Settings/SettingsPage.Data.cs`：科目列表展示改由 4 张映射表生成——同名时显示「名字（老师）」或「名字（Guid 前 8 位）」并自动去重；保存时按 Id 写 `TargetCourseIds`、按名字写 `TargetCourseNames`，重启后优先按 Id 还原选中项。

## 6. 模糊壁纸缓存（掉帧修复）

- `Services/WallpaperCacheService.cs`（新）：内存 LRU(2) → 磁盘 PNG → 后台解码模糊三级缓存；缓存键 = 全路径 + 文件 mtime + 目标宽度 + 生效模糊半径；内存里保留主副本，每次返回 `CopyPixels` 克隆，调用方 Dispose 不影响缓存；所有异常 / 取消都返回 null 由调用方兜底。
- `Views/BackgroundLayer.axaml.cs`：`ApplyWallpaper` 不再在 UI 线程解码 + 模糊整张壁纸，改为 `LoadWallpaperAsync` 走缓存（带请求号，快速改设置时只认最后一次）；缩放改由 `ApplyWallpaperZoom` 单独处理，拖「景深放大」只改 `ScaleTransform`，不重解码。
- `Plugin.cs`：启动时 `WallpaperCacheService.CleanupCache()`，磁盘只留最近 6 张。

## 已知限制

1. 无 ClassIsland 真机环境，`ILessonsService.CurrentTimeLayoutItem` 的实际取值（尤其课前/课间的空值期）需真机确认；取不到时本条保护自动关闭而不是用打开时刻兜底。
2. 壁纸缓存的 `Bitmap.Save` 在 Avalonia 11 是否始终写 PNG 未实测；写入失败不影响本次使用，只影响下次命中。
3. 首次进入大屏仍需生成一次模糊壁纸（会占用 0.2~1s 后台时间），之后命中缓存；换壁纸或改模糊半径会重新生成。
4. 动态图标字形是按 Fluent 20px 字体挑的，若宿主换字体或字号差异过大，个别天气图标可能偏大/偏小。
