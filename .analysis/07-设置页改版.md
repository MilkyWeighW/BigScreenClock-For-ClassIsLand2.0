# 第三轮：设置界面布局重设计（仿 ClassIsland 官方组件）

日期：2026-11-06

## 1. 问题与目标

改造前的 `Settings/SettingsPage.axaml`（730 行）是自成一派的「两列 + 大卡片」布局：

- `Grid ColumnDefinitions="*,360"`：左侧 6 张 1px 描边卡片，每张卡片自带头图标 + 自定义 `Padding="14,12"` 与 `Spacing="12"`；
- 右侧固定 360px 常驻预览列，大屏预览与设置项争宽；
- 层级只靠「卡片标题 17px Bold」，卡片内部又是无序堆叠，设置项与子项之间没有任何从属关系；
- 大量手写 Margin/Padding 叠加，窗口变宽时留白只会更多。

目标：仿照 ClassIsland 官方设置页（`ClassIsland/Views/SettingPages/AppearanceSettingsPage.axaml` 那一套）重做布局，
降低留白、明确「分组 → 设置项 → 子项」的层级，同时**功能、绑定、事件零删减**。

## 2. 官方依据（ClassIsland 2.1.0.1 基线）

SDK 2.1.0.1 的 nuspec 指向 ClassIsland 仓库 commit `15273f82c9d2d55929df83b5fb806e68ee4547c0`，
据此把参考文件从 git 对象里导出到 `D:\ci_clock\_ci_ref_2101\`（仅作参考，不入库）：

- `ClassIsland.Core_StylesBase.axaml`：`StackPanel.settings-container` → `Margin 12 12 18 12`、`MaxWidth = SettingsContainerWidth(960)`、`Spacing 4`；
  `animated-intro` → `StackPanelIntroAnimationBehavior` 进页动画；
- `ClassIsland.Core_Controls_IconText.axaml/.cs`：分组标题控件（`Glyph` 图标 + `Text`，`Spacing=4`）；
- `ClassIsland.Core_Abstractions_Controls_SettingsPageBase.cs`：官方设置页基类（本插件原本就继承它）；
- `ClassIsland_Views_SettingPages_AppearanceSettingsPage.axaml`：行写法范式（`IconText` 组头 → `SettingsExpander` 行 → `SettingsExpanderItem` 子项 → `Separator` 分隔）。

组件可用性：插件经 `ClassIsland.PluginSdk 2.1.0.1 → ClassIsland.Core 2.1.0.1` 传递依赖到
`FluentAvaloniaUI 2.4.1` 与 `ClassIsland.Core`，因此 XAML 里可直接用

```xml
xmlns:controls1="clr-namespace:ClassIsland.Core.Controls;assembly=ClassIsland.Core"
xmlns:controls2="clr-namespace:FluentAvalonia.UI.Controls;assembly=FluentAvalonia"
```

## 3. 新布局结构

按用户第二轮意见，最终采用 ClassIsland 设置窗口的主从结构：**左栏分组设置、右栏固定预览**。

```
UserControl（根不变，code-behind 零改动）
└─ Grid ColumnDefinitions="*,Auto"
   ├─ [列 0] ScrollViewer
   │   └─ StackPanel Classes="settings-container animated-intro"   ← 官方统一边距/间距/进页动画
   │      ├─ 显示内容（IconText F483）        ← 每行 = SettingsExpander，Footer 放原控件
   │      ├─ Separator
   │      ├─ 触发课程（E304）                ← ItemsControl，DataTemplate 根 = SettingsExpanderItem
   │      ├─ Separator
   │      ├─ 运行（E84F）
   │      ├─ 音量检测（EB80）
   │      ├─ 记录参数（E2FE）
   │      ├─ 外观（EC4A）                    ← 含 自定义背景 / 字号 / 上下位置 / 颜色 四组子项
   │      └─ 记录规则（E687）
   └─ [列 1] Border Width=332（Fluent 卡片：CardBackgroundFillColorDefaultBrush）
      └─ 实时预览（IconText E813 + 预览 Border + 进入全屏按钮 + 说明）
```

要点：

1. **左设置、右预览**：右侧预览列独立于左栏滚动之外，滚左栏时预览始终可见；宽度 332 与 ClassIsland 自身的侧边面板（`SettingsWindowNew.axaml` 里实验性功能面板 Width=332）一致。
2. **分组**：`controls1:IconText` 做组标题（Fluent 图标 + 文字），组间 `Separator`，替代原来 6 张描边卡片。
3. **行**：每个开关/滑杆变成 `controls2:SettingsExpander`（`Header` 标题 + `Description` 说明 + `IconSource` 图标 + `Footer` 控件），
   官方自带「左侧标题/描述，右侧控件」的对齐，不再手写 Grid 列宽。
4. **父子项**：关系明确的设置收进 `SettingsExpanderItem` 子项（如「课程信息 → 精确打铃」、「提醒显示 → 天气/预警/倒计时/…」、
   「音量检测 → 安静/良好/一般/吵闹/采样间隔」、「记录参数 → 起算底线/回落窗口/…/调试数据目录」、
   「自定义背景 → 背景主题/背景图片/填充方式/明暗/玻璃 4 行」、「字号 → 3 行」、「上下位置 → 2 行」、「颜色 → 5 个 ColorPicker」）。
   层级由「Expander 缩进 + 子项行」表达，一眼能看出从属。
5. **图标**：全部换成 ClassIsland 自带的 FluentSystemIcons 码点（已用 fontTools 从
   `ClassIsland.Core/Assets/Fonts/FluentSystemIcons-Resizable.ttf` 的 cmap 逐个校验存在），不再用 Lucide `{ci:LI ...}`，
   与官方界面观感一致。

## 6. 未能验证的部分

- 本机未安装 ClassIsland（`D:\`、`%LOCALAPPDATA%`、`Program Files` 三层内均无 `ClassIsland*.exe`），
  无法启动宿主做可视化验收；本轮验收为「编译通过 + 绑定/事件/命名静态对比」。
- 建议实测：把 `cipx/EveningSelfStudyClock.cipx` 装进 ClassIsland 2.1+，重点看
  ① 右栏预览在 332 宽下的比例与文字可读性；② `SettingsExpander` 行在深/浅主题下的对齐；③ 颜色 5 行的 ColorPicker 宽度。
- 右栏宽度固定 332：ClassIsland 设置窗口默认 1240 宽（导航栏展开 283）时左栏约 570，行内 `Footer` 控件仍放得下；
  若把窗口拉到接近最小宽（560，导航栏收起），左栏会被压得很窄——旧版同样如此，后续如需可在右栏加按宽度自动隐藏。
- 若某行在窄窗口下过挤，优先调该行 `Footer` 里控件的 `Width`（现统一 `MinWidth=160`/`Width=180`），不要改容器边距。
