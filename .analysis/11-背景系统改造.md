## 4. 新背景层（`Views/BackgroundLayer.axaml` + `.axaml.cs`）

结构（一个 `UserControl`，不参与布局）：

```
Border ClipBorder (ClipToBounds, CornerRadius)
└─ Grid
   ├─ Border SolidFill    纯色底（其它类型时透明）
   ├─ Image  PriorImage   旧画面：开屏=压暗截图，运行中=上一张背景
   ├─ Image  TargetImage  目标画面（壁纸/自定义图）；壁纸用代码创建的 ScaleTransform 做景深放大
   └─ Border Veil         明暗遮罩（BackgroundDim：负压暗 / 正提亮）
```

- `Apply(settings, isPreview)`：套静态值。预览下不截屏、不播动画；运行中换背景时走 `CrossFadeFrom`。
- `PlayIntroAsync(settings, onTargetReveal)`：
  1. 先 `Apply` 把目标图烘好，三层 `Opacity=0`；
  2. `ScreenCaptureService.CapturePrimaryScreen(0.45)` 取压暗截图，垫在 `PriorImage`；
  3. 壁纸类型 `Task.Delay(420ms)`，让「先压暗、再推近」两拍能被看见；
  4. 回调 `onTargetReveal`（调用方让组件同时淡入），交叉淡入目标层 520ms；
  5. 壁纸额外从 `zoom-0.08` 缓推到 `zoom`（`AnimateZoomTo`），就是「镜头推进」；
  6. 收尾释放截图位图。
- 性能保护：
  - 拖动「景深放大」滑块会连续触发 `Apply`：路径/目标宽度/模糊半径都没变时复用已烘好的位图，只改 `ScaleTransform`，避免每拖一格就重解码 + 模糊整张壁纸。
  - 自定义图片同理按文件名复用，切「填充方式」不重新解码。
  - 旧图先挂在 `PriorImage` 上演淡出，淡完（`FadeMs + 60ms`）才 `Dispose`；提前释放会让正在绘制的位图失效。
  - 离开视觉树 `OnDetachedFromVisualTree → ReleaseBitmaps()` 释放整屏位图。
- 取壁纸失败（锁屏、动态壁纸、权限/文件已删）→ 退回纯色底，不会黑屏。

## 6. 平台能力（新增）

- `Services/WallpaperService.cs`：`GetWallpaperPath()`（CsWin32 `SystemParametersInfo(SPI_GETDESKWALLPAPER)`，失败退 `HKCU\Control Panel\Desktop\Wallpaper`，去引号/展开环境变量）、`LoadWallpaper(path, targetWidth)`。
- `Services/ScreenCaptureService.cs`：`CapturePrimaryScreen(darken = 0.45)`，GDI `GetDC/BitBlt/GetDIBits` 抓主屏、逐像素乘 `1-darken`、alpha=0xFF；句柄在 finally 里按「还原 SelectObject → DeleteObject → DeleteDC → ReleaseDC」释放。
- `Helpers/ImageBlur.cs`：`Blur(Bitmap, radius)`，复用现有 `StackBlur`（CPU，无着色器依赖）。
- `Services/CiTopmostGuard.cs`：`Arrange(clockHwnd)` 先 `SetWindowPos(HWND_TOPMOST)` 大屏，再 `EnumWindows` 找同进程（`Environment.ProcessId`）可见顶层窗口，排除大屏后逐个 `SetWindowPos(HWND_TOPMOST, SWP_SHOWWINDOW)`——后设者在上，于是 CI 在大屏之上。
- `NativeMethods.txt` 增补 GDI/Shell 与窗口 Z 序 API；常量改成枚举名（`SYSTEM_PARAMETERS_INFO_ACTION` / `ROP_CODE` / `SYSTEM_METRICS_INDEX` / `DIB_USAGE` / `SET_WINDOW_POS_FLAGS`）以消掉 PInvoke004 警告，`HWND_TOPMOST` 保留（`HWND` 的静态字段）。

## 9. 已知限制与待真机验收

1. **无宿主可验**：本机未安装 ClassIsland，本轮只能做到「编译通过 + 静态核对 + 组件级 probe 编译」，开屏动画时长、截图效果、置顶 Z 序都需要在装了 CI 的机器上确认。
2. **截图取不到 HDR/受保护画面**：GDI `BitBlt` 只能拿 SDR 近似；DRM/独占全屏可能黑块。截屏失败已兜底为「直接显示背景 + 组件淡入」。
3. **动态壁纸只取静态帧**：符合需求（动态壁纸也取静态图），但取到的是系统登记的静态壁纸文件。
4. **小壁纸会被放大**：`DecodeToWidth(屏幕宽)` 会把 800px 壁纸拉到 1920，清晰度受原图限制（模糊+景深放大后通常看不出来）。
5. **组件变成裸文字**：玻璃删除后组件没有底色，可读性靠「背景明暗」压暗兜底；极亮壁纸下建议把背景明暗调负。
6. **CI 置顶未复位**：大屏收起后没有把 CI 窗口恢复成非置顶（按用户「本次只落实保持置顶」的要求暂不做，后续再细化）。
7. **开屏截图可能拍到 CI 主窗口**：`Show()` 里先显示大屏再隐藏 CI 主窗口，`Loaded` 极快时截图可能带上 CI 主窗口一瞬；如真机上出现，可在 `Show()` 前先 `SetMainWindowVisible(false)`。
